# Evidence Checklist

Capture the following evidence for the assessment submission:

## Required Evidence

- [ ] **Concurrency test output** (`concurrency_test_output.txt`) – showing 1×201 and 9×409
- [ ] **Backup/restore output** (`backup_output.txt`, `restore_output.txt`) – showing successful backup and restore with row counts
- [ ] **Failure drill output** (`drill_output.txt`) – showing detection and recovery from app and DB failures
- [ ] **Smoke test output** (`smoke_test_output.txt`) – showing /health, /ready, login, and doctor list
- [ ] **Trivy scan report** (`trivy-image-report.txt`, `trivy-fs-report.txt`) – security scan results
- [ ] **CI/CD pipeline screenshot** – showing all jobs passing in GitHub Actions
- [ ] **GHCR image screenshot** – showing the published container image with tags
- [ ] **Docker compose ps** – showing all containers healthy
- [ ] **curl -k https://localhost/ready** – showing readiness response

## How to Generate

Most evidence files are auto-generated by the ops scripts (they `tee` output into this directory).

```bash
# Run all evidence-generating scripts
pytest -v tests/test_concurrency.py | tee docs/evidence/concurrency_test_output.txt
bash scripts/backup.sh
bash scripts/restore.sh backups/<latest>.sql.gz
bash scripts/drill_failure.sh
bash scripts/smoke_test.sh
```
